# 🌿 Plantsy – Mini E-Commerce Plant Shop

A modern React-based mini e-commerce application where users can browse plants, search by name, and manage a shopping cart.


---


## ✨ Features

- 🌱 Browse a collection of plants from an API
- 🔍 Search plants by name
- 🛒 Add items to cart
- ➕ Increase / ➖ decrease quantity
- ❌ Remove items from cart
- 💰 Dynamic cart total calculation
- 💾 Cart persists using localStorage
- 📱 Responsive design

---

## 🛠️ Tech Stack

- React (useState, useEffect)
- JavaScript (ES6)
- CSS (custom styling)
- Fetch API
- JSON Server (for backend simulation)
